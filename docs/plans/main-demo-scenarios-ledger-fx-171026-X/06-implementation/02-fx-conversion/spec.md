# FX Conversion Implementation

## Overview

This adds a `fx` module that quotes USD per unit for any ISO currency. It uses open.er-api.com with a daily `fx_rates` cache, falls back to the last stored rate and then to a static table, and stores the quote on every bill and payment.

## Implementation Guidelines

The snippets below are orientative.

```python
STATIC_SOURCE_DATE = date(2026, 10, 1)  # document as "reference date of the static table"

class FxService:
    def __init__(self, repository: FxRepository, provider: OpenErApiProvider, settings: FxSettings) -> None:
        self._repository = repository
        self._provider = provider
        self._settings = settings
        self._fetch_lock = asyncio.Lock()

    async def quote(self, currency: str | None, on: date) -> FxQuote | None:
        if currency is None:
            return None
        code = currency.upper()
        if code == USD:
            return FxQuote(currency=USD, usd_per_unit=Decimal("1"), rate_date=on, source=FxSource.IDENTITY)
        stored = await self._repository.rate_on(code, on, FxSource.OPEN_ER_API)
        if stored is not None:
            return stored
        if self._settings.live_enabled:
            live = await self._fetch_live(code, on)
            if live is not None:
                return live
        cached = await self._repository.latest_since(code, on - timedelta(days=self._settings.max_stale_days))
        if cached is not None:
            return cached.model_copy(update={"source": FxSource.CACHED})
        static_rate = STATIC_USD_PER_UNIT.get(code)
        if static_rate is None:
            logger.warning("fx_rate_unavailable", currency=code)
            return None
        return FxQuote(currency=code, usd_per_unit=static_rate, rate_date=STATIC_SOURCE_DATE, source=FxSource.STATIC_FALLBACK)

    async def _fetch_live(self, code: str, on: date) -> FxQuote | None:
        async with self._fetch_lock:
            stored = await self._repository.rate_on(code, on, FxSource.OPEN_ER_API)  # re-check after lock
            if stored is not None:
                return stored
            try:
                rate_date, rates = await self._provider.fetch_latest()
            except FxProviderError:
                logger.warning("fx_live_fetch_failed", exc_info=True)
                return None
            await self._repository.store_rates(rate_date, rates, FxSource.OPEN_ER_API)
        usd_per_unit = rates.get(code)
        ...
```

- The provider's `rate_date` can be one day before `on` (open.er-api updates once a day). `rate_on(code, on, …)` would then miss on every call and keep refetching. To avoid that, `_fetch_live` returns the quote for the `rate_date` it just stored. The pre-lock lookup uses `latest_since(code, on - 1 day)` restricted to `OPEN_ER_API`. Implement that and give the repository method a name that says so, e.g. `latest_live_since`.
- Precision: `usd_per_unit` uses `Numeric(20,10)`. CLP is about 0.00105, COP about 0.00024 and CLF about 41.5, and all of them fit.
- `amount_usd` stays `Numeric(18,2)`.
- Keep a single conversion point: grep for `to_usd(` after the change, and it must have zero hits.

## Integration Notes

- The frontend (10) renders `fx_source` with `FX_SOURCE_LABELS`: identity "USD", open_er_api "Live rate · ExchangeRate-API", cached "Cached rate", static_fallback "Fallback rate", seed "Historical rate".
