# Storage & Files — S3-only backend, malware scan gate, download proxy

## Overview

Switch the files module from MinIO to real S3 (profile-based auth), gate every upload on the GuardDuty scan-result tag (fail-closed), persist scan status on the `files` row, and expose an authenticated download endpoint for the UI.

## Files to Modify/Create

- `backend/core/config.py` — rewrite `StorageSettings` (S3-only fields, scan tuning; drop `endpoint_url`/`access_key`/`secret_key`)
- `backend/modules/files/storage.py` — `ObjectStorageBackend.__init__`: profile-based `aioboto3.Session`, virtual-host addressing; drop `ensure_bucket` (bucket is Terraform-owned) or keep it no-op behind a flag
- `backend/modules/files/scan.py` (new) — `MalwareScanService`
- `backend/modules/files/models.py` — `FileRow` += `scan_status`, `scanned_at`

- `backend/api/routers/files.py` — new `GET /files/{file_id}/content`
- `backend/container.py` — wire `MalwareScanService`, update storage construction
- `backend/alembic/versions/product/` — autogenerated migration (`files.scan_status`, `files.scanned_at`)

## Implementation Guidelines

`StorageSettings` (final shape):

```python
class StorageSettings(BaseModel):
    bucket: str = "blinka-evidence"
    region: str = "us-east-1"
    aws_profile: str = "panoptico"
    malware_scan_enabled: bool = True
    scan_timeout_seconds: int = 60
    scan_poll_interval_seconds: int = 2
```

`MalwareScanService` (orientative):

```python
class MalwareScanService:
    TAG_KEY = "GuardDutyMalwareScanStatus"
    VALUE_MAP = {"NO_THREATS_FOUND": FileScanStatus.CLEAN,
                 "THREATS_FOUND": FileScanStatus.THREAT,
                 "UNSUPPORTED": FileScanStatus.UNSUPPORTED,
                 "ACCESS_DENIED": FileScanStatus.FAILED,
                 "FAILED": FileScanStatus.FAILED}

    async def wait_for_scan(self, storage_key: str) -> FileScanStatus:
        if not enabled: return FileScanStatus.DISABLED
        deadline = now() + timeout
        while now() < deadline:
            tags = await self._get_tags(storage_key)      # s3.get_object_tagging
            if self.TAG_KEY in tags: return self.VALUE_MAP[tags[self.TAG_KEY]]
            await asyncio.sleep(poll_interval)
        return FileScanStatus.FAILED                       # timeout → fail-closed
```

`FilesService.upload` order (critical): `put` → `wait_for_scan` → persist `scan_status`/`scanned_at` → **only if status in {CLEAN, UNSUPPORTED, DISABLED}** run `_extract_and_record`; otherwise leave `parse_status=PENDING` and return the record so callers can block. Keep the existing `storage_key = f"{owner.user_id}/{uuid4()}_{filename}"` scheme.

Download endpoint:

```python
@router.get("/{file_id}/content")
async def file_content(file_id: UUID, user: CurrentUser = Depends(get_current_user)) -> Response:
    record = await clients.files.get_owned(file_id, user)   # 404 if not owner
    data = await clients.files.read_bytes(record)
    return Response(
        content=data, media_type=record.mime,
        headers={
            "Content-Disposition": f'inline; filename="{safe(record.filename)}"',
            "X-Content-Type-Options": "nosniff",
            "Content-Security-Policy": "sandbox",
        })
```

Auth/ownership follows the existing router pattern (`api/routers/files.py` uses `get_current_user`).

Self-check (no full suite): with `BLINKA_STORAGE__MALWARE_SCAN_ENABLED=false`, `POST /files` with a PDF → 200, `parse_status=parsed`, `scan_status=disabled`; with scanning on and the Terraform bucket, a PDF upload flips to `clean` within the timeout window. `GET /files/{id}/content` returns the exact bytes and headers; another user's file_id → 404.

## Integration Notes

- `FileScanStatus` values and the `GuardDutyMalwareScanStatus` mapping are the contract consumed by module 03 (blocking) and module 05/06 (evidence views, badge copy: clean → "Escaneado por AWS", unsupported → "Sin escaneo").
- `EvidenceFileView` defined here (contracts/files.py) but populated by module 05's repository join.
- Callers that currently rely on `ensure_bucket` at startup (`api/app.py` lifespan) must stop creating the bucket; keep the call only if it becomes a cheap no-op.
